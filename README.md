# AdventureWorks2025
AdventureWorks2025 Analytics — a 2-page Power BI solution built on a T-SQL Data Mart (vw_sales_flat, vw_dim_date, vw_customer_rfm). Features KPI metrics ($109.85M revenue, 31K orders), RFM customer segmentation, product performance analytics, and a dynamic category-monthly matrix powered by SQL window functions.
